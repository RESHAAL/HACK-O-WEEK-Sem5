# HACK-O-WEEK — Semester 5

A collection of weekly practicals, Python programs, machine learning implementations, and learning reports completed during the **HACK-O-WEEK Semester 5 program**.

## 📌 About the Repository

This repository documents my hands-on learning journey through Python programming, mathematical foundations of Machine Learning, supervised and unsupervised learning, model evaluation, dimensionality reduction, ensemble learning, model deployment, and neural networks.

The repository is organized week-wise to make the practicals easy to navigate, understand, and execute.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/RESHAAL/HACK-O-WEEK-Sem5.git
```

### 2. Navigate to the project directory

```bash
cd HACK-O-WEEK-Sem5
```

### 3. Install dependencies

Install the libraries required for the particular practical you want to execute. For example:

```bash
python -m pip install numpy pandas matplotlib scikit-learn
```

Some practicals may require additional libraries such as `xgboost` or `lightgbm`.

### 4. Run a Python practical

Navigate to the appropriate weekly folder and execute the desired Python file:

```bash
python filename.py
```

Replace `filename.py` with the name of the actual Python file.
