## 🛠️ Technologies

- Python
- pip
- Git and GitHub

## ⚙️ How to Run

1. Open a terminal in this folder.
2. Install the dependencies listed in `requirements.txt`:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   python app.py
   ```
