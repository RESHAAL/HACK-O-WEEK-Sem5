# Week 11 & 12 — Dimensionality Reduction

## Overview

This folder focuses on dimensionality reduction techniques used to represent high-dimensional data in a smaller number of dimensions while preserving useful information or structure.

## 📂 Practicals

| File | Topic |
|---|---|
| `PCA.py` | Principal Component Analysis |
| `t-SNE.py` | t-distributed Stochastic Neighbor Embedding |
| `Dimensionality Reduction.txt` | Dimensionality reduction notes |
| `Work Done.txt` | Practical work summary |

## 🛠️ Technologies

- Python
- NumPy
- Scikit-learn
- Data visualization libraries, where required

## ⚙️ Setup

Install the main dependency:

```bash
python -m pip install numpy scikit-learn matplotlib
```

## ▶️ How to Run

Run PCA:

```bash
python PCA.py
```

Run t-SNE:

```bash
python t-SNE.py
```

## 🎯 Learning Objectives

- Understand the purpose of dimensionality reduction.
- Explore Principal Component Analysis (PCA).
- Understand the intuition behind t-SNE.
- Learn how dimensionality reduction can support visualization and exploratory data analysis.

## 📌 Learning Outcome

Develop an understanding of PCA and t-SNE and their applications in exploring high-dimensional datasets.
