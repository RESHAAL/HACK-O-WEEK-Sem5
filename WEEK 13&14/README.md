# Week 13 & 14 — Ensemble Learning and Regularization

## Overview

This folder contains practical implementations of ensemble learning techniques and regularization methods used to improve Machine Learning model performance and manage overfitting.

## 📂 Practicals

| File | Topic |
|---|---|
| `bagging.py` | Bagging |
| `boosting.py` | Boosting |
| `XGBoost.py` | Extreme Gradient Boosting |
| `lightGBM.py` | Light Gradient Boosting Machine |
| `bias-over-underfitting.py` | Bias, overfitting, and underfitting |
| `L1-regularisation.py` | L1 regularization |
| `L2-regularization.py` | L2 regularization |
| `Work Done.txt` | Practical work summary |

## 🛠️ Technologies

- Python
- NumPy
- Scikit-learn
- XGBoost
- LightGBM

## ⚙️ Setup

Install the main dependencies:

```bash
python -m pip install numpy scikit-learn xgboost lightgbm
```

## ▶️ How to Run

Example commands:

```bash
python bagging.py
python boosting.py
python XGBoost.py
python lightGBM.py
```

Other practicals can be executed using their corresponding filenames.

## 🎯 Learning Objectives

- Understand ensemble learning.
- Explore bagging and boosting.
- Implement XGBoost and LightGBM.
- Understand bias, variance, overfitting, and underfitting.
- Explore L1 and L2 regularization.

## 📌 Learning Outcome

Gain hands-on experience with ensemble methods and regularization techniques used in practical Machine Learning workflows.
