# Week 15 & 16 — Model Deployment and Neural Networks

## Overview

This folder covers introductory model deployment concepts, perceptrons, activation functions, forward and backward propagation, loss functions, optimization algorithms, and neural network implementation using NumPy.

## 📂 Practicals

| File | Topic |
|---|---|
| `pickel_model.py` | Model serialization using Pickle |
| `joblib_model.py` | Model serialization using Joblib |
| `perceptron.py` | Perceptron |
| `activation_function.py` | Activation functions |
| `forward_backward.py` | Forward and backward propagation |
| `loss_optimizers.py` | Loss functions and optimization |
| `neural_network_numpy.py` | Neural network implemented using NumPy |
| `work_done.txt` | Practical work summary |

## 🛠️ Technologies

- Python
- NumPy
- Scikit-learn
- Pickle
- Joblib

## ⚙️ Setup

Install the main dependencies:

```bash
python -m pip install numpy scikit-learn joblib
```

## ▶️ How to Run

Run an individual practical:

```bash
python perceptron.py
```

To execute the NumPy neural network practical:

```bash
python neural_network_numpy.py
```

Other scripts can be executed using their respective filenames.

## 🎯 Learning Objectives

- Understand saving and loading trained models.
- Explore perceptrons and activation functions.
- Understand forward propagation and backpropagation.
- Learn about loss functions such as Mean Squared Error and Binary Cross-Entropy.
- Explore optimization methods such as SGD and Adam.
- Implement a basic neural network using NumPy.

## 📌 Learning Outcome

Understand introductory model serialization and neural network training concepts, including activation functions, loss calculation, gradient computation, and parameter updates.
