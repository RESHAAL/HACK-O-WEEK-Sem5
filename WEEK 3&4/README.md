# Week 3 & 4 — Python, NumPy, and Pandas

## 📌 Overview

This folder contains practical implementations covering Python programming fundamentals, data structures, functions, object-oriented programming, and introductory data manipulation using NumPy and Pandas.

## 📂 Practicals

| File | Description |
|---|---|
| `array.py` | Array operations |
| `broadcasting.py` | NumPy broadcasting |
| `dectionary.py` | Dictionary operations |
| `dict.py` | Dictionary examples |
| `functions.py` | Python functions |
| `list.py` | List operations |
| `oops.py` | Object-oriented programming |
| `panda1.py` | Pandas data manipulation |
| `vectorization.py` | Vectorization concepts |
| `dataVisualozation.py` | Data visualization |
| `work_done.txt` | Summary of completed practicals |

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib or other visualization libraries, where required

## ⚙️ Setup

Install the required libraries:

```bash
python -m pip install numpy pandas matplotlib
```

## ▶️ How to Run

Open a terminal in this folder and run an individual practical:

```bash
python functions.py
```

Replace `functions.py` with the name of the practical you want to execute.

## 🎯 Learning Objectives

- Understand Python lists and dictionaries.
- Create and use functions.
- Learn the basics of object-oriented programming.
- Perform array operations and understand broadcasting.
- Explore vectorization.
- Manipulate data using Pandas.
- Visualize data using Python libraries.

## 📈 Learning Outcomes

Develop a foundation in Python programming, data structures, and introductory data manipulation techniques used in Machine Learning.
