# Week 5 & 6 — Mathematical Foundations of Machine Learning

## Overview

This folder focuses on the mathematical concepts required to understand Machine Learning algorithms, particularly linear algebra, derivatives, and gradient-based optimization.

## 📂 Practicals

| File | Topic |
|---|---|
| `vectors.py` | Vectors |
| `matrices.py` | Matrices |
| `dot_product.py` | Dot product |
| `eigen.py` | Eigenvalues and eigenvectors |
| `derivatives.py` | Derivatives |
| `derivative_at_a_perticular_point.py` | Derivative at a particular point |
| `gradient.py` | Gradients |
| `chain_rule.py` | Chain rule |
| `backdrop_intuiton.py` | Backpropagation intuition |
| `WORK_DONE.TXT` | Practical work summary |

## 🛠️ Technologies

- Python
- NumPy
- Linear algebra
- Differential calculus

## ⚙️ How to Run

Execute an individual practical from this folder:

```bash
python vectors.py
```

Replace `vectors.py` with the name of the practical you want to run.

## 🎯 Learning Objectives

- Understand vectors and matrices.
- Perform dot product operations.
- Explore eigenvalues and eigenvectors.
- Understand derivatives and gradients.
- Apply the chain rule.
- Develop an intuition for backpropagation and optimization.

## 📌 Learning Outcome

Build the mathematical foundation needed to understand model training, dimensionality reduction, and neural networks.
