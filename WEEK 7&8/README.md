# Week 7 & 8 — Regression and Classification

## Overview

This folder contains practical implementations of supervised Machine Learning algorithms for regression and classification tasks.

## 📂 Practicals

| File | Topic |
|---|---|
| `Linear_Regression.py` | Linear Regression |
| `Polynomial_Regression.py` | Polynomial Regression |
| `Ridge_Regression.py` | Ridge Regression |
| `Lasso.py` | Lasso Regression |
| `Logistic_Regression.py` | Logistic Regression |
| `KNN.py` | K-Nearest Neighbors |
| `Train_test.py` | Train-test splitting |
| `Work_Done.txt` | Practical work summary |

## 🛠️ Technologies

- Python
- NumPy
- Scikit-learn

## ⚙️ Setup

Install the main dependencies if they are not already installed:

```bash
python -m pip install numpy scikit-learn
```

## ▶️ How to Run

For example:

```bash
python Linear_Regression.py
```

Run other algorithms by replacing the filename with the corresponding script.

## 🎯 Learning Objectives

- Understand supervised learning.
- Implement Linear and Polynomial Regression.
- Explore Ridge and Lasso regularization.
- Understand Logistic Regression for classification.
- Implement K-Nearest Neighbors.
- Learn how to split data into training and testing sets.

## 📌 Learning Outcome

Gain practical experience with foundational supervised learning algorithms and understand how different models are applied to prediction tasks.
