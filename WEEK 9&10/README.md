# Week 9 & 10 — Model Evaluation, Feature Engineering, and Clustering

## Overview

This folder covers important Machine Learning workflows, including model evaluation, feature preprocessing, pipeline construction, and unsupervised clustering.

## 📂 Practicals

| File | Topic |
|---|---|
| `model_evaluation.py` | Model evaluation |
| `cross_validation.py` | Cross-validation |
| `feature_eng.py` | Feature engineering |
| `feature_scaling.py` | Feature scaling |
| `Scikit-learnPipeline.py` | Scikit-learn pipelines |
| `K-MeansClustering.py` | K-Means clustering |
| `HierarchicalClustering.py` | Hierarchical clustering |
| `dbscan.py` | DBSCAN clustering |
| `Work Done.txt` | Practical work summary |

## 🛠️ Technologies

- Python
- NumPy
- Pandas
- Scikit-learn

## ⚙️ Setup

Install the required libraries:

```bash
python -m pip install numpy pandas scikit-learn
```

## ▶️ How to Run

For example:

```bash
python model_evaluation.py
```

Run other practicals individually using their respective filenames.

## 🎯 Learning Objectives

- Evaluate Machine Learning model performance.
- Understand cross-validation.
- Perform feature engineering and scaling.
- Build preprocessing and modeling pipelines.
- Explore K-Means clustering.
- Understand hierarchical clustering and DBSCAN.

## 📌 Learning Outcome

Understand how preprocessing, validation, evaluation, and clustering contribute to a reliable Machine Learning workflow.
